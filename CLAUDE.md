# AUTOHIM — redesign of autohim.ps.me

Client site for **AUTOHIM**, a car-care chemicals shop in Ternopil (вул. Пантелеймона Куліша, 2, daily 09–19, +380 73 429 26 19, ФОП Погорілець В. М.). Instagram/Telegram/TikTok @autohim_ter. Old shop: autohim.ps.me (ps.me / Poster shop builder, Next.js; its `__NEXT_DATA__` carries the whole catalogue).

Brief from the user: redesign that looks more expensive, **black + blue**, rich animations, comfortable and easy to click, built like ~/Desktop/aluabri; product photos from the old site.

**Talk to the user in Russian.** Site copy is **Ukrainian only** (`lang="uk"`, ’ apostrophes, «» quotes). Read `docs/STATUS.md` first (open client questions, launch checklist).

## Commands
```bash
npm run dev                              # port 3013
npm run build && npm start               # production on :3013
kill $(lsof -ti tcp:3013 -sTCP:LISTEN)   # restart: only our port, only LISTEN (otherwise it also kills Chrome)
npm run lint && npx tsc --noEmit         # must stay clean
open -a "Google Chrome" http://localhost:3013
research/.venv/bin/python -I scripts/fetch_photos.py .   # old shop photos → originals/
research/.venv/bin/python -I scripts/catalog.py          # rebuild src/data/catalog.json + public/images/p
research/.venv/bin/python -I scripts/build_video.py .    # Pexels clips → public/video
```
`research/.venv` is a symlink to `~/Desktop/aluabri/research/.venv` (Pillow, numpy, imageio-ffmpeg).

## Stack
Next.js 15 App Router · React 19 · TypeScript strict · plain CSS (`src/app/globals.css`, tokens in `:root`) · next/font (Unbounded display, Manrope body, JetBrains Mono labels) · no animation libraries (IntersectionObserver + rAF: `src/lib/motion.ts`, `src/components/Effects.tsx`). All motion respects `prefers-reduced-motion`. Images are pre-built WebP, so `<img>` is used on purpose (lint rule off).

## Data pipeline (raw material in `research/` and `originals/`, both gitignored)
- `research/site.json` = `__NEXT_DATA__` of autohim.ps.me (1021 products, 80 categories, contacts). One photo per product, descriptions on ~35.
- `scripts/catalog.py`: cleans names (К2→K2, GEYON→GYEON, glued words), maps old top categories to 12 sections (old slugs kept for redirects), brand-only categories (GYEON, KOCH, WOLF, SOFT99, RITUALS, SONAX) become brands and get a section by keywords, detects brands from names, parses descriptions, writes `public/images/p/<pos_id>.webp` (800) + `<pos_id>s.webp` (360). Cached: delete a file to rebuild it.
- `scripts/cutout.py`: removes clean white studio backgrounds (flood fill from the frame + soft matte). 865/1005 photos are cut out. Holes in white bottles are invisible on the light card stage; on dark showcase blocks only hand-checked ids are used (see `src/app/page.tsx`, `Sections.tsx`, `featuredBrands`). Do not use 128 or 1239 on dark backgrounds.
- `scripts/build_video.py`: Pexels clips with a "midnight blue" grade. The hero clip is cropped to hide a third-party studio logo.

Old ps.me URLs (/category/…, /product/<pos_id>, /contacts) redirect. Search indexing stays off until `NEXT_PUBLIC_SITE_LIVE=1`.
